# Talkaton downloads

Release archives in this folder are generated from the matching source folders:

- `talkaton-desktop-source.zip` contains the installable Talkaton Desktop PWA shell.
- `codeaton-source.zip` contains the Codeaton product page, browser workspace, native app wrappers, and build scripts.

Talkaton Desktop and Codeaton both ship direct `.dmg` and `.exe` installers. These builds are not yet notarized with Apple or signed with a Microsoft code-signing certificate, so the operating system may show a first-run security warning.
